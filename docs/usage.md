# 灵动笔记使用说明

## 启动方式
双击桌面上的「灵动笔记」快捷方式即可打开。
第一次启动时会在后台自动启动一个小型本地服务，
之后每次双击会直接打开笔记本窗口（无浏览器地址栏）。

## 功能简介
1. 记录内容：点工具栏「＋ 文本」添加文字块，双击文字即可编辑，
   文字块可以像卡片一样在页面上任意拖动摆放。
2. 截图贴纸：点「📷 截图」选择屏幕/窗口后，会弹出裁剪框，
   拖动选区或四角即可自由框选范围，确认后只把选中的部分贴入；
   也可以用 Win+Shift+S 截屏后，在笔记本里直接 Ctrl+V 粘贴。
   选中贴纸后：拖右下角手柄缩放、拖顶部圆点旋转、拖贴纸移动。
3. 加粗 / 高亮：双击进入编辑后选中文字，用浮动工具条
   加粗、荧光高亮、改文字颜色、调字号、对齐。
4. 自由移动：文本块和贴纸都不是传统一行行的文档，
   所有内容都可以随意摆放；拖空白处移动视角，Ctrl+滚轮缩放。

## 保存与备份
- 默认自动保存到项目根目录下的 notes.json 文件。
- 文字输入会实时同步，停止输入约 900 毫秒后自动保存；编辑过程中也可以直接按 Ctrl+S。
- 点「另存为」可自定义保存位置和文件名，之后会自动持续保存到
  该文件；下次打开应用时会自动继续使用这个文件。
- 点「打开」可选择之前保存的笔记文件继续编辑。
- 打开前会检查文件格式；仅打开文件不会改写内容，之后的编辑才会自动保存。
- 如果提示默认笔记加载失败、写入已暂停，请使用「打开」选择有效笔记，或用「另存为」保存恢复出的内容。
- 工具栏「保存」可立即保存；「导出」可生成独立备份文件。
- 默认文件保存前会记录浏览器恢复副本。重启时若它与磁盘内容不同，会显示双方的修改时间并询问恢复；旧格式的未知时间会明确提示。选择恢复后先检查内容，再保存或继续编辑；仅恢复、切换后台或关闭窗口不会立即覆盖磁盘文件。
- 默认笔记每次内容变化保存时，旧文件会留在 `backups/`，自动保留最近 20 个版本。可以通过「打开」检查历史副本，再「另存为」保存到新位置；不要直接编辑需要保留的历史副本。手工放入的其他文件不参与自动清理。
- 自定义「另存为」文件不由本地服务管理，因此不生成上述自动历史备份；可继续使用「导出」保留独立副本。
- 复制整个文件夹即可整体备份。

## 常用快捷键
| 快捷键 | 操作 |
| --- | --- |
| Ctrl+S | 保存 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| Ctrl+D | 复制选中的块 |
| Delete | 删除选中的块 |
| Ctrl+滚轮 | 缩放页面 |

编辑文字时，Ctrl+Z／Ctrl+Y 撤销或重做文字输入；退出编辑后，快捷键操作整次画布变更。Ctrl+Shift+Z 也可以重做。打开另一个笔记文件后，会重新开始记录操作历史。
