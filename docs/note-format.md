# 笔记文件格式

当前支持 JSON 格式版本 `1` 和 `2`。只有文字与图片时仍保存为版本 1；包含笔迹时保存为版本 2，防止旧程序忽略笔迹后覆盖文件。旧程序不能打开版本 2，请使用支持画笔的程序。读取时校验整个文档，任何一处无效都会拒绝加载；不会先加载前半部分，再在后半部分失败。

## 根对象

| 字段 | 约束 |
| --- | --- |
| `version` | 必须为数字 `1` 或 `2`；缺失或其他版本不被接受 |
| `updatedAt` | 内容修改的 Unix 毫秒时间戳；可省略或为 `0`，表示旧笔记时间未知；需为非负整数且不超过 JavaScript 日期范围 |
| `items` | 必须是元素数组，可以为空 |
| `paper` | 可省略，默认 `lines`；可选 `lines`、`grid`、`blank` |
| `images` | 可省略，默认空对象；键为图片资源标识，值为 Base64 图片 data URL |

支持带 UTF-8 BOM 的 JSON 文件。未知字段不会进入内部数据模型。

## 元素

所有元素必须包含：

- `id`：不重复的正安全整数，并预留后续分配标识的空间。
- `type`：`text`、`image`，版本 2 还支持 `ink`。
- `x`、`y`：有限数字，允许负数。
- `w`：大于零的有限数字。
- `z`：非负安全整数。
- `rot`：可省略，默认为 `0`，必须为有限数字。

文字元素还包含：

- `html`：字符串，可以为空。
- `fontSize`：可省略，默认为 `18`，必须为大于零的有限数字。
- `align`：可省略，默认为 `left`；可选 `left`、`center`、`right`。

图片元素还包含：

- `h`：大于零的有限数字。
- `srcId`：必须引用 `images` 中实际存在的资源。

图片仅接受 `data:image/...;base64,...` 形式，校验编码字符与长度；不接受远程 URL 或原型相关资源键。此校验不负责解码图片像素，也不承担富文本 HTML 安全过滤。

笔迹元素（`ink`）还包含：

- `h`：大于零的有限数字。
- `color`：`#RRGGBB` 格式的六位十六进制颜色。
- `strokeWidth`：1 到 32 之间的有限数字，表示画布中的线宽。
- `points`：1 到 10000 个 `[x, y]` 坐标对，各坐标是 0 到 1 之间的有限数字，按元素宽高归一化保存。单点显示为圆点。

每笔是独立元素，渲染在文字与图片上方，按 `z` 排列笔迹之间的层次。缩放笔迹时按比例调整路径，线宽保持不变；缩放画布时两者一起缩放。移动卡片不会带动笔迹。

## 读取与写入

“打开”在校验与替换确认成功后才切换文件目标，且不立即写回文件。“导入备份”修改当前笔记，保留撤销记录。只有编辑后自动保存、明确保存或另存为时才写入相应目标。
